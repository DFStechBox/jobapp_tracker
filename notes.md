Add __lucide-react icon library__ to project by running the following command in your terminal:
  _npm install lucide-react_

Next/Link is a built-in component in Next.js that allows for client-side navigation between pages in your application. It provides a way to create links that enable users to navigate without triggering a full page reload, resulting in a faster and smoother user experience. No need to install it separately, as it is included with the Next.js framework. You can import it in your components like this:
  _import Link from "next/link"_

Install mongodb and mongoose to your project by running the following command in your terminal:
This will install the official MongoDB Node.js driver and Mongoose, which is an Object Data Modeling (ODM - Object Document Modeler) library for MongoDB and Node.js. It provides a straightforward, schema-based solution to model your application data and includes built-in type casting, validation, query building, and business logic hooks.
  _npm install mongodb mongoose_
